# 日内做 T v2 优化设计

日期：2026-07-19

## 1. 目标与结论

本轮目标不是继续叠加 RSI、MACD、KDJ 或布林带，而是修复当前均值回归模型的三个根因，并用样本外结果决定是否启用 v2 默认参数：

1. 当前策略允许在 `abs(zscore) >= stop_z` 时开仓，低波动或价格平台会产生极端 Z-score，随后立即触发 `risk_restore`。
2. 当前回测 API 没有把 SQLite `stock_limit_prices` 传入已有的成交限制模型，导致涨停价上的倒 T 卖出未被拦截。
3. 未恢复配对跨日后丢失活动方向，持仓被永久锁定，账户增量损益被长期方向暴露污染。

基线复验覆盖 2026-01-05 至 2026-07-14，共 53,362 根分钟线、112 个交易日。341 次入场中 340 次完成，完整配对净损益为 `-28,172.90` 元；账户相对被动持有为 `-134,191.26` 元。265 次 `risk_restore` 合计 `-143,110.16` 元，而 71 次正常回归退出合计 `+115,979.65` 元。唯一未恢复配对发生于 603629.SH 涨停日，解释了约 `-106,018.36` 元差额。

## 2. 研究依据

- A 股日内反转和日内动量同时存在，第二个半小时更可能出现反转，尾盘更可能延续早盘方向：[Chu、Gu、Zhou 2019](https://www.sciencedirect.com/science/article/pii/S1544612318307414)。
- 日内波动与成交量存在明显时段季节性，不能把统一滚动阈值视为全天同分布：[Andersen、Bollerslev 1997](https://www.finance.martinsewell.com/stylized-facts/volatility/AndersenBollerslev1997b.pdf)。
- 高波动和高成交量也可能代表信息型趋势，不能机械解释为超买或超卖：[Gao 等 2018](https://www.sciencedirect.com/science/article/pii/S0304405X18301351)。
- 跳跃常与公司信息有关，跳跃后立即逆势容易把价格重估误判为噪声：[Lee、Mykland 2008](https://galton.uchicago.edu/~mykland/paperlinks/LeeMykland-2535.pdf)。
- 有交易成本时必须设置不交易区，预测收益需覆盖佣金、税费、价差、滑点、冲击与不确定性缓冲：[Martin、Schoneborn 2011](https://arxiv.org/abs/1103.4934)。
- 上交所 2026 交易规则用于 T+1 可卖数量、申报数量、竞价时段和价格限制：[上交所交易规则（2026 年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)。

## 3. v2 默认信号

v2 保留 session VWAP、偏离 Z-score、EMA、VWAP slope 和 volume ratio，只新增三个正交门控：

### 3.1 极端冲击门控

入场必须同时满足：

```text
entry_z <= abs(zscore) < max_entry_z
```

默认 `entry_z=1.75`、`max_entry_z=2.40`。这会拒绝已经进入止损区、低方差放大或事件跳跃产生的极端信号。`max_entry_z` 必须小于 `stop_z`。

### 3.2 可交易波动门控

使用最近 10 根一分钟收益的总体标准差：

```text
realized_vol_10_bps = std(close.pct_change(), 10, ddof=0) * 10000
```

候选研究值为 `realized_vol_10_bps >= 20`。该门控用于排除价差和最低佣金主导的低波动噪声，不是波动越高越好；极端 Z-score 仍由上一层拒绝。两年冻结研究未验证该门控，因此运行默认值最终降为 `0bp`（关闭），20bp 只保留为研究参数。

### 3.3 时段门控

默认只在 `10:00 <= time < 10:30` 开新配对，关闭下午新开仓。30 根 warmup 使实际首个信号自然落在 10:00。恢复腿不受时段门控影响。

早期半年顺序重放只用于定位根因和冻结候选协议，不能作为晋级证据。最终决策只使用第 8 节的两年连续样本外、最终 holdout 与成本压力结果。日内累计趋势 50bp 门控在最终四折中仍只有 21 对，本轮只保留为实验参数，不作为默认硬门控。

## 4. 执行与状态修复

### 4.1 涨跌停门控

回测 API 批量读取 `stock_limit_prices` 并传给 backtester。任何新入场信号若当前价格已在涨停或跌停价附近，一律拒绝；当日精确上下限价缺失时也必须失败关闭。恢复腿仍尝试成交并记录失败原因。成交只允许发生在信号后紧邻的一分钟，并继续按下一分钟开盘、成交量上限和方向性滑点处理。

### 4.2 跨日恢复

活动配对、方向、数量、入场价和配对 ID 必须跨交易日保留。未能当日恢复时：

- 当日计一次恢复失败；
- 下一可用交易日禁止新开仓；
- 第一根可交易 bar 起优先恢复原底仓；
- 成功后才解除锁定；
- 最终仍未恢复时单独报告 `open_pairs_at_end`。

数据缺口不得让配对状态消失，也不得把长期方向暴露伪装成做 T 损益。

### 4.3 数据质量

结果增加每只股票观测交易日、共同交易日、缺失日和最长缺口。当前两只股票在 2026 年分钟数据均存在缺口，尤其 2026-04-15 至 2026-04-23、2026-06-08 至 2026-06-16。优化结论必须同时显示数据质量警告。

## 5. 参数与接口

`StrategyParams` 和 API 增加：

- `max_entry_z=2.4`
- `realized_vol_window=10`
- `min_realized_vol_bps=0.0`（20bp 候选未通过两年样本外，仅保留可调研究项）
- `entry_start_time=10:00`
- `entry_end_time=10:30`（右开区间）
- `allow_afternoon_entries=false`
- `max_adverse_day_move_bps`（可选实验门控，默认禁用）

前端显示 v2 风控摘要，并允许调整前三个数值参数；真实下单继续保持关闭。

## 6. 验证

1. 单元测试逐项覆盖极端 Z、低波动、时段、涨跌停、跨日恢复和参数约束。
2. 消融顺序固定为：v1 -> 极端 Z -> 时段 -> 实现波动 -> 可选趋势门控。
3. 使用至少两年分钟数据做滚动 walk-forward；参数只能由历史训练窗口决定。
4. 分别报告 symbol、正/反 T、时段、退出原因和每个测试折。
5. 成本压力使用默认成本、滑点 5bp/边和 10bp/边；成交量参与率使用 2.5% 和 5%。
6. v2 只有在多个时间折均改善且恢复失败为零时才可设为默认模拟盘参数；无论结果如何都不得开启真实委托。

## 7. 后续候选（不在本轮）

- 市场/行业分钟残差与同分钟 MAD 标准化。
- 基于历史同类信号的条件期望和回归半衰期。
- QMT 五档价差、microprice、queue imbalance 和 OFI。
- 部分成交、撤改单与成交延迟压力模型。

这些能力需要额外历史指数、行业或 Level-2 数据，不能用仅实时可见字段回填历史回测。

## 8. 两年冻结验证结果

实际运行区间为 2024-07-19 至 2026-07-14，共 223,282 根分钟线、466 个观测交易日、464 个共同交易日。使用 252 日最小训练窗、63 日连续测试折和 63 日最终 holdout；权威日历 480 日中有 14 日没有分钟数据，精确涨跌停价覆盖 906/930 个观测股票日，澜起科技缺 2 个观测交易日。覆盖门槛因此未通过。

| 固定消融 | 四个测试折合计净损益 | 完成配对 | 负收益折 |
|---|---:|---:|---:|
| v1 兼容基线 | -88,824.88 | 643 | 4/4 |
| 极端 Z + 频次护栏 | -29,100.62 | 322 | 4/4 |
| 再加 10:00-10:30 时段 | -5,397.65 | 215 | 3/4 |
| 再加 20bp 最低波动 | -10,551.55 | 140 | 2/4 |
| 再加 50bp 日内趋势门控 | +7,972.03 | 21 | 2/4 |

20bp 候选在 3/3 个开发折和最终 holdout 均优于 v1 兼容基线，最终未恢复配对为零，但名义折并非全为非负；5bp/边和 10bp/边滑点压力合计分别为 `-21,516.60`、`-39,226.65`。50bp 日内方向门控虽转正，但仅 21 对且两折为负，不足以支持晋级。自动建议为 `do_not_promote`。

20bp 候选拆解为：正 T `+5,026.92`、倒 T `-15,578.47`；603629.SH `+10,717.12`、688008.SH `-21,268.67`；正常回归退出 `+66,896.78`、`risk_restore` `-78,297.99`、尾盘强制恢复 `+849.66`。该结果可以提出按股票、方向和条件期望校准的新假说，但不能用已观察的 holdout 直接事后关闭方向并宣称通过。`v1_compatible` 仍受 `max_entry_z < stop_z` 等新安全不变量约束，并非危险旧版的逐位复现。
